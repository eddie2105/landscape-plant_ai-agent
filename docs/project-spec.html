景觀植物 AI 系統

這份文件以最新分檔後的專案為準。主程式在 景觀植物AI系統/，舊路徑集中在 舊版相容/，根目錄檔案只負責啟動。

.\.venv\Scripts\python.exe -m streamlit run .\landscape_matrix_query.py
這個程式在做什麼 使用者用自然語言描述景觀植物需求，系統把文字轉成搜尋條件，從植物矩陣篩選候選植物，再用 AI 產生推薦說明或景觀提案。
現在的主架構 新主程式在 景觀植物AI系統/。資料夾名稱對應責任：設定、資料、查詢、推薦、AI回答、介面。
重要分工 Python 負責資料載入、正規化、filter、搜尋、排序、驗證。AI 負責解析模糊語意與產生 grounded answer。Streamlit 負責互動介面。
UI 資料 AI 輸出

資料從哪裡來，往哪裡去

.env / credentials由 設定/settings.py 讀取 OpenAI key、Google Sheet id、service account 路徑。
Google Sheets / CSV資料/matrix_loader.py 優先讀 Google Sheets，失敗時讀本地 CSV fallback。
DataFrame 正規化資料/normalizer.py 處理 boolean、月份欄位、多值顏色、plant_id 字串。
UI filter options從資料中產生 sidebar 可選的植物型態、花色、果色、葉色。
使用者問題介面/streamlit_app.py 收自然語言問題與手動 filter。
Filter 合併查詢/filters.py 合併 known、AI、manual filters。
搜尋與推薦查詢/search.py 篩資料，推薦/scoring.py 排序與選推薦。
AI 與畫面AI回答/ 產生回答，介面/ 顯示卡片、矩陣、圖表。

景觀植物AI系統/設定/settings.py設定.env、merged matrix Sheet 設定、proxy helper。

舊版相容/舊路徑封存保留舊 import 參考，不作為主動開發位置。

使用者輸入如何變成搜尋 filter

實際搜尋不直接交給 AI。系統先用本地規則抓明確條件，再用 AI 補語意，最後讓 sidebar 手動條件覆蓋。
